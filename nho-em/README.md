# Một chiếc ping từ anh

Trang web tĩnh, tối ưu cho điện thoại. Mở `dist/index.html` trực tiếp hoặc chạy `python3 -m http.server 5173 --directory dist` từ thư mục này.

Ảnh thật đang dùng: `dist/assets/breakfast.jpeg` và `dist/assets/work.jpg`. Ảnh hiển thị theo tỷ lệ gốc để không cắt mất nội dung; ảnh nằm trong chồng ảnh bỏ túi nhỏ, bấm xem lớn để mở ảnh đầy đủ.

Trang kết thúc bằng lời nhắn “Rảnh thì nhắn tui nè.”, không có form hoặc chức năng gửi tin.

Tương tác: chạm mèo hoặc nút chọc để đổi lời thoại; mắt mèo nhìn theo con trỏ; chạm ảnh để xem câu đùa; chạm nền để hiện tim. Tôn trọng cài đặt giảm chuyển động trên thiết bị.

Bản ảnh bỏ túi: nút lật ảnh, hộp thoại xem lớn (đóng bằng nút hoặc Escape), trò bắt bug và ký hiệu code chuyển động.

Giao diện terminal đen/xanh neon, canvas mưa trái tim phủ nền; có nút tạm dừng và tự dừng khi tab ẩn hoặc thiết bị bật giảm chuyển động.
